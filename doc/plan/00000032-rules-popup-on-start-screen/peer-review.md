# Peer Review — Story 00000032: How-to-play rules page

## Summary

The branch adds a "How to play" button as the first start-screen choice and a
new `rules` screen in `App.tsx`'s existing screen union, carrying a full-width
header, six sections in two columns and ten illustrated figures drawn from the
game's own piece artwork on 5×5 cutouts of a real Battle board. The figure data
is pure `.ts` (`figures.ts`) and is checked on every run against the real
`legalDestinations`, `legalAttacks` (under all four diagonal-flag combinations)
and `resolveCombat`; `RuleFigure.tsx` derives every piece, ring, arrow and
removal mark from that same square data with no per-figure coordinate and no
`figure.id` branch anywhere in the geometry, which is exactly what the story
asked for. The hard constraints hold: `git diff --stat` against the merge base
touches only `README.md`, `src/App.tsx`, `src/app/StartScreen.tsx`,
`src/app/rules/**` and this story folder — nothing under `src/rules/`, none of
`Board.tsx`/`FullBoard.tsx`/`PlayBoard.tsx`/`AccessibleGrid.tsx`, no new
dependency and no router. The six section sentences, the header lines and the
six headings were compared character-for-character against `story.md`'s fixed
copy and match exactly.

Verification run from the repository root:

- `npm run typecheck` — **clean**, no findings.
- `npm run lint` — **clean**, no findings.
- `npm test` — **clean**, 35 files / 945 tests passed.
- (Additionally, for the plan's five-check gate: `npm run format:check` and
  `npm run build` both clean.)

The implementation plan does include a step that verifies `README.md` is still
up to date for this story (Step 9, "Nothing else moved, and the README", whose
verification bullet is "Read the updated `README.md` end to end and confirm it
is accurate, in register, and still carries the companion-rulebook link"), so
no comment is raised on that point.
