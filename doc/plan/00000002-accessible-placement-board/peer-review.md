# Peer Review — Story 00000002: Accessible placement board

## Summary

This branch ports the Phase 1 placement board onto the shared
`AccessibleGrid` (rectangular view, every visible cell focusable, only home
cells actionable, `initialFocus` seeded to the first home square), adds a new
pure wording module (`placementAnnouncement.ts`, 28 tests) driving square
labels, tray labels and a board live region, replaces the native `disabled`
attribute with `aria-disabled` + no-op on the tray, the self-disabling
placement controls and the start screen, adds `eslint-plugin-jsx-a11y`, and
clears the three accessibility findings deferred from story 00000023. All
twelve plan steps are `committed` and Gates A/B/C are recorded as passed.

Verification from the repository root: `npm run typecheck` **passes**,
`npm run lint` **passes** (clean, no warnings — which also confirms both
`eslint-disable-next-line` directives in `AccessibleGrid.tsx` are still live
rather than stale), `npm test` **passes** (32 files, 745 tests). `npm run
format:check` is also clean. `src/engine/**` and `src/encoding/**` are
untouched, and every touched file's header comment names this story and step.
The plan does contain a dedicated README-accuracy step (Step 12), so no
comment is raised on that requirement itself; the decision it reached is
raised as #12 below for the owner's judgement.

The three deferred story 00000023 findings were each verified against the
diff and are genuinely fixed: **#3** — `gameAnnouncementRegion` is now one
JSX constant rendered at the same child index (4) of `<main>` in all three
branches, so React keeps a single persistent `role="status"` node across the
game-choice → placement transition; **#10** — the new
`useEffect(..., [configuration])` refocuses the persistent `<h1>` on the
`null` → non-`null` transition; **#13** — `StartScreen`'s "Play against the
computer" now uses `aria-disabled` + a no-op `onClick`, keeping its
`aria-describedby` note reachable. No correctness bug was found in the
placement grammar itself; the findings below are announcement-coverage gaps,
scope/documentation discrepancies, and small cleanups.
